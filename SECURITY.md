# Security and data handling

This is a portfolio release, not an independently audited product. Use synthetic data when evaluating it. Do not expose local web servers publicly. Local web applications have no multi-user authentication or role separation; bind only to loopback. Back up local data before upgrades.

Offline analyzers do not contact scanned systems. Reports may contain sensitive file paths or metadata; review them before sharing. Never run an analyzer on files you are not authorized to inspect.

Do not paste credentials in public issues. Contact the maintainer privately via the GitHub profile.
